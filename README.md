🇮🇳 Namma Kannada AI — Smart Language Learning with Spaced Recall

Learn Kannada step by step. Practise with confidence. Remember for longer.

Namma Kannada AI is an interactive language-learning application designed to help beginners learn Kannada vocabulary, understand meanings, practise everyday expressions, and improve recall through structured learning and revision.

The platform combines Kannada script, transliteration, meanings, guided lessons, interactive flashcards, practice exercises, and progress tracking in one learning experience.

Its learning approach follows five stages:

Learn → Understand → Practise → Recall → Review

The goal is to make Kannada more accessible to English- and Hindi-speaking beginners through a simple, engaging, and structured learning experience.

✨ Features

- 📚 Structured Learning Modules: Learn Kannada vowels, greetings, introductions, pronouns, questions, and practical expressions.
- 🗂️ Interactive Flashcards: Explore Kannada words, transliterations, meanings, and translations.
- 🌐 English and Hindi Support: Understand Kannada vocabulary through English meanings and Hindi equivalents where provided.
- 🎯 Practice Exercises: Test your understanding with interactive multiple-choice questions.
- 💡 Smart Hints: Use hints during practice to support learning and understanding.
- ✅ Immediate Feedback: Identify mistakes and reinforce correct answers through practice.
- 🧠 Active Recall: Practise retrieving vocabulary from memory rather than relying only on repeated reading.
- 🔄 Spaced Revision: Revisit challenging words and items due for review.
- 🏆 Confidence-Based Review: Identify vocabulary that may need additional practice.
- 📈 Learning Progress: Track learning activity through dashboard indicators such as daily goals, streaks, mastered vocabulary, and review status.
- 📱 Responsive Interface: Navigate lessons, flashcards, and practice through a clean, card-based design.

🔁 How It Works

Namma Kannada AI uses a five-stage learning workflow to guide learners from their first encounter with a word to independent recall.

1. Learn 📘

Discover Kannada vocabulary in its original script alongside transliteration and meaning.

Example:

Detail| Example
Kannada| ನಮಸ್ಕಾರ
Transliteration| Namaskara
Meaning| Hello / Greetings

2. Understand 💡

Connect vocabulary with meanings, translations, grammar, examples, and everyday usage where provided.

3. Practise 🎯

Answer interactive questions to check understanding and recognise appropriate Kannada expressions.

4. Recall 🧠

Challenge yourself to retrieve previously learned vocabulary with fewer or no hints.

5. Review 🔄

Revisit challenging words and items due for review to reinforce learning over time.

This process connects vocabulary learning, guided practice, recall, and revision in a single workflow.

🚀 Getting Started

Prerequisites

Install Node.js and npm before running the application.

1. Install Dependencies

Open a terminal in the project directory containing "package.json" and run:

npm install

2. Configure the Environment

Check ".env.example" for required environment variables. Configure a local ".env" file only if the application requires it.

Never commit API keys, passwords, or other secrets to the repository.

3. Start the Development Server

For a project configured with the standard Vite development script, run:

npm run dev

Open the local address displayed in the terminal.

4. Build for Production

If the corresponding script is defined in "package.json", run:

npm run build

To check the available project scripts, run:

npm run

Use the commands defined in your repository's "package.json" if they differ from these examples.
